📁 Cómo subir las fotos
Las fotos se guardan en tu repositorio de GitHub para que siempre estén disponibles en todos los dispositivos, sin depender del celular.

Cada menú tiene su carpeta y dentro van 3 archivos: jorge.jpg, sonia.jpg y kevin.jpg. También puedes usar .png o .webp.

🚀 Pasos para subir una foto
1. Ve a tu repositorio en GitHub.com
2. Navega a la carpeta del menú (ej: fotos/deficit/atun-con-papa/)
3. Clic en "Add file → Upload files"
4. Sube jorge.jpg, sonia.jpg y kevin.jpg
5. Clic "Commit changes"
6. En la app, el punto verde 🟢 aparece cuando hay foto cargada.
